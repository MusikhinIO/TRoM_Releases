# TRoM_Releases

Public distribution repository for the **TRoM launcher**

This repo holds only what the launcher needs to update itself anonymously:

- `latest.json` — update manifest fetched by the launcher
- Release assets — patch files attached to GitHub Releases

Source code stays in a private repository. No tokens or credentials are required to read anything here — the build script uses a fine-grained PAT scoped to this repo only
